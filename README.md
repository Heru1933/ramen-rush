Ramen Rush — a precision ramen-shop cooking game. Boil noodles with perfect timing, simmer the right broth, stack toppings in ticket order, and serve before patience runs out. Five days, four broths (shoyu, miso, tonkotsu, tantanmen), a VIP food critic on the final day, combos, tips, and upgrades between days.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network requests, plain static files.
